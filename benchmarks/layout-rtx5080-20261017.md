## 对照条件

两种模式均保留现有蒙版缓存、FP32 权重/输入/输出、`float32_matmul_precision=highest`、
`matmul.allow_tf32=False`。可选原生蒙版算子在两种计时模式中均关闭，用于隔离布局转换的贡献。
并未更改 SageAttention、cuDNN 精度、模型权重或工作流。

两种模式各做一次完整预热；按 A/B、B/A、A/B、B/A 完成四组交错对照。
每次运行前空闲至少 10 秒且核心温度不高于 50°C；冷却时间不计入节点耗时。
每秒记录温度、频率、利用率和驱动温度降频标志；正式测试最高温度 67°C，
**所有正式轮次和预热均未观测到温度降频**。

测试前确认生产 ComfyUI 队列为空，并释放其空闲模型缓存，将显存腾出供独立测试进程使用。
每个分块前后以及节点前后均查询生产队列；队列变忙或查询失败就终止本轮。
HTTP 检查开销计入两种模式的耗时。生产服务未重启，没有提交或取消生产任务。
CPU、系统 RAM 及桌面渲染仍为共享资源；本结果仅覆盖这一模型与尺寸的 DAT 节点。

此前的 2070 记录含热降频，不能据两张显卡的百分比直接推断无降频时的架构差异。
早先未完成的 5080 原型测试不参与本报告统计。

## 复现

使用 ComfyUI 自己的 Python；先自行确认显存充足且队列空闲：

```powershell
$env:CUDA_VISIBLE_DEVICES = '<5080 的完整 GPU UUID>'
python benchmarks/benchmark_layout.py --comfyui 'D:/ComfyUI/ComfyUI' --model '4x-UltraSharpV2.safetensors' --image 'D:/images/test.png' --output 'D:/results/layout5080.json' --gpu-uuid $env:CUDA_VISIBLE_DEVICES --gpu-name '5080' --pairs 4 --cooldown-temperature 50 --cooldown-min-seconds 10 --queue-url 'http://127.0.0.1:8188/queue'
```

脚本不自动释放缓存；`--queue-url` 为可选的只读空闲检查。
不包含用户图片、权重或工作流。机器可读数据：[`layout-rtx5080-20261017.json`](layout-rtx5080-20261017.json)。
