# RTX 5080 专用 CUDA 蒙版内核实测

2026-10-17，Windows x64、RTX 5080 / SM 120、Python 3.13.16、PyTorch 2.14.1+cu130、CUDA Toolkit 13.0、MSVC 14.44.35207、Spandrel 0.4.2。

对照双方都启用同一个 DAT 缓存；本次只替换缓存未命中时的蒙版生成，不包含先前 CPU → GPU 缓存优化的收益。
专用算子用一个 CUDA launch 生成两个方向的连续蒙版，直接输出 `0/-100`，消除切片赋值、置换、减法和多次 masked_fill 的中间分配。

## 初轮基准

以下为可选后端接入前的同算法原型对照。算子测量每组预热 3 次、20 次 CUDA event 样本取中位数，包含 CPU 提交间隙及输出分配的影响，并非纯 kernel 指令执行时间。

| 512×512，窗口 8×16，双方向蒙版 | 缓存插件的 PyTorch 路径 | 专用 CUDA 算子 |
|---|---:|---:|
| FP32 生成 | 4.448 ms | 0.327 ms |
| FP16 生成 | 3.050 ms | 0.184 ms |
| BF16 生成 | 2.588 ms | 0.182 ms |
| FP32 生成额外峰值显存 | 546 MiB | 256 MiB |

真实模型使用 `4x-UltraSharpV2.safetensors`，输入 1920×960、输出 7680×3840，仅测 `ImageUpscaleWithModel`。模型先加载，双方各预热一次，排除预热后跑 6 组交替顺序配对：

| 指标 | PyTorch + 缓存 | CUDA + 同一缓存 |
|---|---:|---:|
| 整段耗时中位数 | 12.498637 s | 12.458800 s |
| 每次超分蒙版生成次数 | 4 | 4 |
| PyTorch 峰值已分配显存 | 4.469533 GiB | 4.469533 GiB |

该轮中位数之比为 **1.00320×，约节省 0.32%**。6 组配对都略快，配对节省中位数 47.65 ms；对这 6 组数据做 10,000 次 bootstrap，配对中位数节省的 95% 区间为 7.07–77.68 ms。样本较少、收益接近运行波动，不应外推为稳定的全工作流提速。
全部模型输出张量逐元素一致，最大绝对误差为 0。输出比较和复制参考输出在计时之外。
缓存已消除了绝大多数重复蒙版生成，因此算子本身十余倍提速只带来很小的整段收益；模型其他工作区决定了整段峰值显存。

## 验证范围

最终接入版本通过 26 项本地测试，包括 CPU/CUDA、后端回退、缓存命中/清理、真实 ComfyUI 节点接入。
原生数值对照含 33 组：FP32/FP16/BF16，不同大小和方向的窗口、零偏移、整窗口偏移，以及 480×512、512×512 大蒙版；全部逐元素一致。
测试还覆盖非默认 CUDA 流和参数校验。原型的 Compute Sanitizer memcheck 为 0 errors。

最终接入版本的模型计时复测为 **NOT_RUN**：ComfyUI 开始持续处理视频队列，队列保护阻止了复测。
上述 6 组有效模型数据来自内核原型，最终版本保留相同算法，增加参数校验和可选后端选择；不将原型计时标成最终接入版本的实测。
并发视频生成期间的一轮微基准已弃用。脚本在检测到 ComfyUI 队列繁忙时停止，不清队列、不取消用户任务。

这些验证不代表完整扩散工作流、其他超分模型、RTX 2070、Linux 或所有 PyTorch/CUDA 组合均已验证。
原始匿名数值见 [cuda-rtx5080-20261017.json](cuda-rtx5080-20261017.json)，不包含输入图片、权重或个人工作流。

## 复现

先构建可选后端、运行原生测试，再在 GPU 空闲时测量。以下命令从插件目录运行，使用 ComfyUI 的 Python；路径与模型名按实际安装替换：

```powershell
python build_native.py --device cuda:0 --cuda-root 'C:/Program Files/NVIDIA GPU Computing Toolkit/CUDA/v13.0'
$env:DAT_CACHE_TEST_CUDA = '1'
$env:DAT_CACHE_TEST_NATIVE = '1'
$env:COMFYUI_ROOT = 'D:/ComfyUI/ComfyUI'
python -m unittest discover -s tests -v
python benchmarks/benchmark_cuda.py masks --output mask-results.json
python benchmarks/benchmark_cuda.py model --comfyui-root 'D:/ComfyUI/ComfyUI' --model '4x-UltraSharpV2.safetensors' --image 'D:/images/input.png' --pairs 6 --output model-results.json
```

基准默认检查 `http://127.0.0.1:8188/queue`；使用其他地址时传 `--server-url`。
无服务的离线环境可以显式传 `--server-url ''`，并自行确保 GPU 空闲。
运行真实模型基准需要 ComfyUI 的模型和 Pillow/NumPy 依赖；脚本不会下载模型或上传图片。
